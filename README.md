# Mascotas perdidas · Bogotá

Python + SQL (SQLite) + Streamlit.

## Ejecutar
```bash
cd src
pip install -r requirements.txt
python -m streamlit run app.py
```

## Formato de los reportes
`nombre mascota, tipo animal / raza, color, fecha y hora de pérdida, descripción`
Ej.: `Rocky, Perro - Labrador, Café, 15/11/2026 08:30, Se perdió en Suba con collar rojo`
